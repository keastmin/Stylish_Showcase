VECTOR JET — 로봇 기동용 제트 VFX 안내

빠르게 보기
1. Unity 메뉴 Tools > ProjectR > Vector Jet > Open Preview Scene을 선택합니다.
2. Play를 누르고 Game 뷰를 봅니다. 미리보기는 4.8초 주기로 반복됩니다.
3. 세 스테이션을 비교합니다.
   01 / HOVER HOLD: 짧은 점화 뒤 일정 출력으로 유지하는 체공 연출.
   02 / VECTOR IMPULSE: 급기동을 위한 짧고 분명한 세 번의 분사.
   03 / FULL IGNITION: 더 긴 불꽃과 강한 점화로 출력을 확인하는 연출.
4. PLAY / PAUSE는 미리보기 타이밍 진행을 전환하고, RESTART는 처음부터 재생합니다.
   PLAYBACK 슬라이더는 타이밍 진행 속도, ALL / 01·02·03 SOLO는 표시 대상을 조절합니다.
   PAUSE는 출력 타이밍과 GPU 불꽃의 움직임을 함께 멈춥니다.

에셋과 범위
모든 에셋은 Assets/06_VFX/VectorJet 아래에 있습니다.
- Preview/VectorJet_Preview.unity: 독립 미리보기 씬.
- Prefabs/VectorJet_Thruster.prefab: 재사용 가능한 불꽃과 점화 조명.
- Prefabs/VectorJet_NozzlePreview.prefab: 노즐 모델과 불꽃을 함께 담은 선택용 미리보기 프리팹.
- Graphs/VectorJet.vfx: 편집 가능한 네이티브 VFX Graph.
- Shaders/JetVolume.shadergraph: 시선 방향에 따라 메시 가장자리를 부드럽게 줄이는 VFX용 Shader Graph.
- Models/: Blender에서 제작한 노즐, 불꽃 외피, 압축 셀 FBX.
- Textures/JetFlameMask.png: 이 효과용 이미지 생성 도구로 만든 마스크.
- Source~/VectorJet.blend: Blender 원본. Source~ 폴더는 Unity 자동 임포트 대상에서 제외됩니다.
- Source~/build_vectorjet_models.py: 모델 생성 원본 스크립트.

플레이어·로봇 스크립트에는 연결하지 않은 독립 프리팹입니다. 불꽃만 필요하면 Thruster, 노즐까지 함께 확인하려면 NozzlePreview를 사용합니다.
원점은 분사 시작점이며 로컬 +Z 방향으로 불꽃이 나옵니다. Unity 1 unit = 1 m 기준입니다.

주요 조절값
Throttle: 0–1 출력. 0은 꺼짐, 1은 최대 출력입니다.
JetLength: +Z 길이 배율. 길이 1로 제작된 기본 불꽃 모델에 적용되어 미터 기준 길이 조절에 사용할 수 있습니다.
JetWidth: X/Y 폭 배율. 1은 모델의 기본 폭이며 1m 너비를 뜻하지 않습니다.
CoreTint / ShockTint / FringeTint: 코어, 압축 셀, 외곽 필라멘트의 HDR RGB 색 입력.
FlameMask / CoreMesh / ShockMesh: 마스크와 Blender 형상 입력.

프리팹의 VectorJetEffect에서 throttle, jetLength, jetWidth, coreTint, shockTint, fringeTint를 조절할 수 있습니다. 세 색상은 HDR 색 선택기를 지원합니다.
이 컴포넌트가 활성화되어 있으면 해당 Graph 속성을 매 프레임 갱신하므로, 이 컴포넌트의 값을 조절합니다.
SetThrottle(값)은 0.03 이하에서 그보다 큰 출력으로 올라갈 때 Ignite 이벤트를 자동으로 보냅니다.
Ignite() 또는 VisualEffect.SendEvent("Ignite")는 짧은 압력 플래시를 발생시킵니다. 가시적인 분사를 위해 Throttle도 0보다 크게 설정합니다.
Cutoff()는 출력을 0으로 설정합니다.

Graph 구조
네 개의 GPU 시스템으로 구성합니다.
01 청보라 연소 외피: Blender 메시와 마스크의 UV 흐름.
02 밝은 압축 다이아몬드: Blender 셀 메시와 출력에 따른 발광.
03 축 방향 필라멘트: 이동하는 얇은 불꽃 입자와 짧은 수명·난류.
04 Ignite 플래시: 점화 이벤트에 반응하는 짧은 입자 분사.
메시 출력은 JetVolume Shader Graph를 사용해 마스크의 세부 무늬와 부드러운 가장자리를 함께 표현합니다.

형태와 시간 설계
실제 제트의 좁은 축 방향 흐름, 연결된 밝은 압축 구간, 반투명 외피, 부드럽게 무너지는 끝부분을 참고했습니다.
청백색·청보라색과 절제된 따뜻한 압축부를 조합하여 로봇의 작은 추진기에서도 읽히도록 조정합니다.
미리보기의 점화·유지·차단 시간과 출력 맥동은 게임 연출을 위한 설계값입니다. 실제 엔진의 측정 시간이나 물리 시뮬레이션 결과가 아닙니다.

화면 확인
어두운 배경과 회색 배경에서 측면·사선의 실루엣을 비교합니다. 밝은 압축 셀 사이의 어두운 간격, 반투명 외피, 자연스러운 끝부분이 유지되는지 확인합니다.
PAUSE로 정지 상태를 확인한 뒤, 재생 상태에서 점화·체공·짧은 분사·완전 소멸의 타이밍을 확인할 수 있습니다.
