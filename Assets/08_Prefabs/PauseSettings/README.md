# Pause settings

`Resources/PauseSettings.prefab` is an editable UGUI Canvas with TextMesh Pro labels. The gameplay bootstrap creates a single persistent instance when a scene contains a `PlayerCore`; it also supports placing the prefab in a scene manually.

- **ESC** opens the menu and pauses gameplay; ESC or **RESUME** closes it.
- **MASTER VOLUME** controls the global AudioListener volume. **MUTE** retains the selected volume. Settings are saved locally with PlayerPrefs.
- **TEST SOUND** plays a short preview while gameplay audio is paused. **RESET** restores the default volume and clears mute.
- Opening and closing use unscaled animation. The art, orbital details, equalizer, and hover effects continue while game time is stopped.
- Cursor, camera input, audio pause, and the previous time scale are restored on close. Combat timing and cutscene playback are integrated with the pause state.

The prefab is generated by `Editor/PauseSettingsBuilder.cs`. Use **Tools > Project R > Pause Settings > Rebuild Prefab** to rebuild its authored layout. Rebuilding replaces manual changes to the prefab; edit the builder first if those changes should survive a rebuild. All interactive controls, text, and decorative elements remain separate objects in the saved prefab.

The artwork is `Art/PauseSanctuary.png`, generated with the built-in image generation tool. Its exact prompt is preserved in `Art/GenerationPrompt.txt`. The interface uses the project's Roboto Condensed TMP fonts and its existing faceted HUD graphic.

The menu intentionally offers one master volume control, covering music, ambience, combat, and cutscene audio through the global listener. No per-category audio routing changes are required.

For visual editing in Prefab Mode, temporarily set the root CanvasGroup alpha to 1; the runtime controller hides the window in Awake. **Capture Layout Previews** renders the authored menu without changing an open scene.

## Verification

Validated in Unity 6000.5.8f1 on 2026-11-07. The explicit Play Mode verifier passed 81 checks, including real ESC input, UI control callbacks, settings persistence, unscaled decoration, camera/input restoration, hitstop deadlines, and nested/cancelled cutscenes. All five interactive controls also passed live UGUI pointer-raycast checks. Layouts were visually checked at 1920x1080 and 1280x720, plus the live Game View.

Run **Tools > Project R > Pause Settings > Verify Runtime (Play Mode)** in a gameplay scene to reproduce the runtime checks. The verifier restores prior preferences and temporary input devices. Reports and screenshots are written under `output/PauseSettings/` at the project root. The existing gameplay scenes do not need to be modified or saved to install this feature.
