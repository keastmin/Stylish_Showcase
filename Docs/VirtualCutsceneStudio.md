# Q 궁극기 가상 컷씬 스튜디오

Unity 메뉴 **Tools → Character → Player → Q - Cutscene Studio**에서 연다.

현재 `PlayerUltimate.asset`의 `cutscene`에 `UltimateCutscene.asset`이 연결되어 있다. Q 궁극기가 사용 가능한 상태에서 Q를 누르면 1.8초의 예제 연출을 재생한 뒤 기존 궁극기 공격 시퀀스로 돌아간다. 기존 궁극기의 쿨다운, 사용 조건, 이동·타격 데이터는 유지한다.

## 편집 순서

1. 상단에서 컷씬 에셋을 선택하거나 **새 컷씬 / 복제**로 만든다.
2. **무대**에서 배경색, 배경 프리팹의 위치·회전·크기, 스카이박스, 바닥과 두 조명을 설정한다. 배경 프리팹을 미리보기 화면에 드롭할 수도 있다.
3. **캐릭터**에서 외형을 지정한다. 외형을 비워 두면 현재 씬 플레이어의 모델을 복제한다. 애니메이션을 추가하고 시작 시각, 표시 길이, 원본 시작 시각, 배속, 반복을 설정한다. 모델의 리그와 호환되는 클립을 사용한다.
4. **카메라**에서 여러 샷을 추가한다. 각 샷의 시작·끝 위치, 바라보는 위치, 시야각, 기울기, 흔들림을 설정한다. **자유 탐색**을 켜고 드래그로 회전하거나 휠로 줌한 뒤 **탐색 구도 → 시작 / 끝**으로 저장한다.
5. **이펙트**에서 프리팹, 시작·길이, 위치·회전·크기를 정한다. 파티클은 시간축을 앞뒤로 움직여도 같은 시각의 상태를 보여준다.
6. **사운드**에서 클립, 시작·길이, 원본 시작, 볼륨, 배속/피치, 반복, 페이드를 정한다. 여러 소리를 겹칠 수 있다.
7. **재생·연결**에서 전체 시간, 상하 검은 띠, 시작·끝 페이드, Esc 건너뛰기를 정한다. **현재 컷씬을 Q 궁극기에 연결**하고 상단의 **저장**을 누른다.

시간축 위 눈금을 누르거나 드래그하면 해당 시각을 확인한다. 색 구간을 선택하면 그 구간의 설정이 열린다. 구간을 좌우로 드래그하면 시작 시각이 바뀐다. 기본은 60fps 단위이며 Shift를 누르면 자유롭게 이동한다. 편집은 Unity Undo/Redo를 지원한다.

Space는 재생/일시정지, 좌우 화살표는 1프레임 이동이다. 동작/오디오 클립을 화면에 드롭하면 현재 시각에 추가한다. **재생·연결 → 현재 미리보기 프레임 저장**은 렌더링한 3D 프레임을 PNG로 저장한다.

Play Mode에서는 Game 화면의 Q 또는 **재생·연결 → 게임에서 Q 궁극기 시전**으로 확인한다. 편집 중인 에셋 변경은 다음 시전부터 반영된다.

## 재생 규칙과 지원 범위

- 모든 컷씬 시각은 실제 초다. 전투 슬로모션과 히트스톱에 영향을 받지 않는다.
- 겹친 애니메이션은 나중에 시작한 구간을 사용한다. 구간 사이 빈 시간에는 이전 마지막 자세를 유지한다. 클립의 루트 이동과 Animation Event는 전투에 적용하지 않는다.
- 카메라는 다음 샷 시작 시점에 컷 전환되고, 해당 샷 내부에서는 시작·끝 구도를 보간한다. 샷 종료 후 다음 샷까지는 끝 구도를 유지한다.
- 외형·배경·이펙트는 시각 오브젝트로 복제한다. MonoBehaviour, 충돌, Rigidbody, 기존 오디오와 카메라, PlayableDirector를 제거하므로 게임 로직은 실행되지 않는다. 스크립트로 생성하는 효과 대신 렌더러/ParticleSystem이 있는 시각 프리팹을 준비한다. VFX Graph의 시간축 스크러빙은 지원하지 않는다.
- 편집기 오디오는 읽을 수 있는 PCM 데이터를 합성해 미리 듣는다. 최대 120초까지 합성하며, 데이터를 읽을 수 없는 압축/스트리밍 클립은 Play Mode에서 확인한다. 게임에서는 원래 AudioClip을 재생한다.
- 예제 바닥 머티리얼을 연결하면 바닥 색은 그 머티리얼에서 편집한다. 기본 바닥색은 머티리얼을 비웠을 때 사용한다.
- 기본 컷씬은 예제 동작과 두 카메라 샷, 전환 사운드를 제공한다. 배경과 VFX 프리팹은 원하는 에셋을 선택해 추가한다.

## 전투와의 분리

`VirtualCutsceneDefinition`은 연출 데이터만 저장한다. `VirtualCutsceneStage`가 편집기와 게임에서 동일한 애니메이션·카메라·파티클 평가를 수행한다.

런타임은 별도 물리 씬과 `Cutscene Studio` 렌더 레이어를 사용한다. 전용 카메라의 출력을 RenderTexture에 그려 화면 전체에 표시한다. 전투 시간, 전투 업데이트, 원래 애니메이터, 게임 카메라와 입력, 전투 오디오를 정지한다. 컷씬 오디오는 별도 소스로 재생한다. 히트스톱의 남은 시간도 유지한다.

컷씬 동안 `Cutscene Display Camera`가 화면 출력을 유지하여 Game View의 `No cameras rendering` 알림을 방지한다. 이 카메라는 월드 오브젝트와 후처리를 렌더링하지 않으며, 실제 컷씬 영상은 기존 RenderTexture와 전체 화면 UI로 표시한다. 정상 종료나 취소 시 즉시 비활성화되고 임시 씬과 함께 제거된다.

`PlayerUltimateRuntime.Begin`이 기존 궁극기 데이터를 복사하고 쿨다운을 예약한다. 컷씬 중에는 공격 시간이나 0초 타격/큐를 진행하지 않는다. 정상 종료나 허용된 Esc 건너뛰기 후 전투 화면을 복구하고 공격을 시작한다. 재생기 비활성화, 소유 플레이어 비활성화 또는 중도 취소 시에는 공격을 취소하고 전투 상태를 복구한다. 임시 카메라, 씬, RenderTexture와 PlayableGraph를 정리한다.

## 검증

메뉴의 **Validate Cutscene Studio (Edit Mode)**는 복제 모델, 원본 보존, 애니메이션 스크러빙, 샷 경계와 오디오 합성, 미리보기 씬 정리를 검사한다.

**Validate Cutscene Studio (Play Mode)**는 실제 궁극기 진입점에서 전투 정지, 피해/큐 지연, 자연 종료, 재시전, 재생기 중단과 상태 복구, 임시 씬 정리를 검사한다. 검증에는 복제한 설정을 사용하고 테스트 편집을 저장하지 않는다. Game View를 열고 플레이가 진행되는 상태에서 실행한다.

2026-11-05, Unity 6000.5.8f1 검증: Edit Mode 검사 22개, 프레임별 관찰을 포함한 Play Mode 검사 289개 통과. 기존 궁극기의 런타임 32개·시퀀스 15개·타격 중 히트스톱 6개도 통과했다. 시간축 드래그와 한 번의 Undo, 실제 Input System Q 입력 후 컷씬 렌더링·전투 복귀를 확인했다. 시험 편집과 런타임 상태는 복원했으며 씬 파일을 저장하지 않았다.
