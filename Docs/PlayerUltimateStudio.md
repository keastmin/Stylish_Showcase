# 플레이어 Q 궁극기 툴

현재 입력은 **Q = Ultimate**, **E = Skill**이다. Q는 여러 원본 애니메이션 클립을 순서대로 재생하는 궁극기이며, E는 기존 타임라인과 게이지 조건을 사용한다. Q 시안의 기본 쿨다운은 시전 시작부터 8초이며, 게이지는 소비하지 않는다. 2026-11-07 화면 통합으로 Q와 E가 같은 헤더·클립 선택·재생 도구·타격 시간축·상세 편집 디자인을 사용한다. E 편집은 `PlayerSkillStudio.md`를 참고한다.

## 시작하기

1. Player가 있는 씬에서 `Tools > Character > Player > Q - Ultimate Studio`를 연다.
2. 편집 데이터와 실제 Player 연결을 확인한다. 기본 데이터는 `Assets/07_Datas/Player/PlayerUltimate.asset`이다.
3. `클립 · 루트모션` 탭에서 AnimationClip을 드래그하거나 `추가할 클립`에 지정하고 `+ 추가`를 누른다. 위·아래 버튼으로 순서를 조절한다. 같은 원본 클립을 여러 번 넣어도 각 구간은 별도의 타격·이펙트 설정을 갖는다.
4. 편집할 클립을 선택하고 사용 시작·종료 시각, 배속, 루트 이동·회전·높이 적용을 설정한다. 추가·교체 시 원본 이동은 자동으로 읽는다. 원본 에셋이 바뀌어 갱신 안내가 나오면 `원본 이동 읽기 / 갱신`을 누른다.
5. `Scene 미리보기`에서 선택 클립 집중 재생 또는 전체 시퀀스 재생을 사용한다. `타격 · 범위`에서 타격 시점과 위치·회전·크기를 조절한다. Scene 핸들과 숫자 입력은 같은 데이터를 편집한다.
6. 저장 후 Play Mode에서 Q를 사용한다. 변경값은 다음 시전부터 적용된다. 이미 시작한 궁극기는 시작 시점의 설정을 유지한다.

타임라인의 타격은 **마름모 마커 하나**로 표시한다. 마커를 드래그하면 선택한 원본 클립의 프레임에 맞춰 시점을 옮긴다. 타격 상세에서 초 또는 프레임 번호를 입력하거나 `마커로 이동`을 눌러 해당 자세로 이동한다. `마커 −1f` / `마커 +1f`로 한 프레임씩 조정할 수도 있다. 기존 타격의 시작 시각은 마커 시각으로 보존하며, 종료 시각은 더 이상 사용하지 않는다.

타임라인의 타격 이름 옆 `↑` / `↓` 또는 타격 목록의 `위로` / `아래로` 버튼으로 행 순서를 바꿀 수 있다. 해당 타격의 마커 시각과 범위·피해 설정은 유지되며 Undo를 지원한다. 행 순서는 재생 시각을 바꾸지 않는다.

데미지 필드와 이동·회전·크기 핸들은 해당 마커의 프레임에만 표시한다. 선택 중이어도 다른 프레임이나 `사용`을 끈 타격은 표시하지 않는다. 상면·측면 도식에도 같은 기준을 적용한다. 범위를 편집하려면 타격을 선택하고 `마커로 이동`을 누르면 된다. 전체 재생에서는 실제 재생 중인 클립의 마커만 표시한다.

## 편집 기준

- 타격과 이펙트의 편집 시간은 **선택한 원본 클립의 초**다. 앞 구간의 길이·순서·배속이 달라져도 해당 모션에 대한 시점은 유지된다. 사용 시작·종료 시각 안에 있는 마커만 실행하며, 양끝 시각의 마커도 포함한다.
- 구간 길이는 `(원본 종료−원본 시작) / 구간 배속`이다. 전체 스킬 배속은 전체 시퀀스에 적용하고, 미리보기 배속은 관찰에만 사용한다.
- 위치는 플레이어 바닥 기준점에서 시전 방향을 기준으로 한 로컬 미터다. X는 오른쪽, Y는 위, Z는 전방이다. 박스 크기는 전체 폭·높이·깊이이며 구체는 반경이다.
- 판정은 플레이어의 실제 물리 위치와 현재 시퀀스 루트 방향을 따른다. 실제 판정과 편집기의 범위는 `UltimateFieldGeometry`를 공유한다. 시퀀스의 마커 통과는 이동이 반영된 물리 처리에서 검사하므로, 긴 프레임에 지나간 마커도 그 처리 시점의 실제 위치를 사용한다. 과거의 플레이어·적 위치를 되감아 판정하는 방식은 아니다.
- 재생 시각이 마커에 도달하거나 지나가면 해당 범위를 **한 번만 검사**한다. 그 순간 대상이 없어도 검사는 끝나며, 나중에 들어온 대상은 타격하지 않는다. 프레임이 건너뛰어져도 지나간 마커는 빠뜨리지 않는다. 여러 콜라이더를 가진 대상도 한 마커에서 중복 검사하지 않으며, 같은 시각의 서로 다른 마커는 별도 타격이다.
- 기본 타격과 피해량은 조작감을 확인하기 위한 초안이다. 완성된 애니메이션 타격 분석이나 밸런스 수치가 아니다.
- 시퀀스 이동은 플레이어 Avatar로 추출한 원본 루트 모션을 사용한다. 새 구간의 시작 루트 변환을 제거하고 이전 구간의 마지막 위치·방향에서 이어간다. 원본 `.anim` 파일은 수정하지 않는다.
- Q는 대기·달리기뿐 아니라 공격·회피·반격·피격·히트스톱 도중에도 현재 행동을 정리하고 즉시 시작한다. 쿨다운, 사망, 일시정지, 이미 재생 중인 Q/컷씬 제한은 유지한다.

## 컷씬과 입력 취소 시점

`연결 · 실행` 탭의 **Q 시작 컷씬**에 연결된 컷씬을 Q 입력 직후 재생한다. **연결된 컷씬 편집**으로 Cutscene Studio를 열 수 있다. 컷씬이 끝나는 순간 전투 스킬을 시작하며, 컷씬을 비우면 바로 전투 스킬을 시작한다.

후딜레이 중 다른 행동으로 이어가려면 재생 도구 아래의 **입력 취소 시점 지정**을 켠다. 미리보기에서 원하는 자세를 찾고 **현재 위치부터 입력 취소**를 누르거나 **취소 가능 (전체 초)**를 입력한다. **취소 위치 보기**는 해당 클립과 자세로 이동한다. 이 시각부터 유효한 이동·일반 공격·회피·E 입력이 있으면 Q를 조기 종료하고 해당 행동을 같은 업데이트에서 시작한다. 입력이 없으면 시퀀스 끝까지 계속 재생하고 자연 종료한다. 체크를 끄면 전체 시퀀스가 끝날 때까지 입력 취소를 허용하지 않는다.

전체 시퀀스 띠와 해당 클립 시간축의 **노란 취소 가능선**은 입력 취소가 열리는 시점이다. 뒤쪽을 옅은 노란색으로 표시하며, 이 구간에 남은 타격·연출 개수를 알려 준다. 입력이 없으면 이 마커들도 정상 실행한다. 실제 입력으로 취소하면 남은 판정·연출·루트 이동을 정리한다. 회피 횟수가 없거나 E 게이지가 부족한 입력만으로는 Q를 취소하지 않는다. 동시에 유효한 입력이 들어오면 회피 → E → 일반 공격 → 이동 순서로 처리한다. 이동 키를 계속 누르고 있으면 취소 가능 시점부터 달리기로 이어진다. 그 전에 누른 일회성 공격·회피·E 입력은 예약하지 않는다.

취소 시각은 구간 배속을 반영한 전체 시퀀스 기준이며 컷씬 시간은 포함하지 않는다. 실제 취소 가능 시간은 이 시각을 전체 스킬 배속으로 나눈 값이고, 자연 종료 시간은 전체 시퀀스 길이를 배속으로 나눈 값이다. 컷씬·히트스톱·일시정지 중에는 입력 취소를 처리하지 않는다.

**다음 동작 블렌드 (초)**는 입력 취소 또는 자연 종료 시 다음 애니메이션으로 자세를 섞는 시간이다. 기본값은 0.15초이며 0으로 두면 즉시 전환한다. 다음 행동은 블렌드를 기다리지 않고 시작한다. 이 설정도 Undo와 저장을 지원하며 다음 Q 시전부터 반영된다.

현재 연결된 데이터는 전체 약 4.833초 중 **3.75초부터 입력 취소 가능**, **0.15초 블렌드**로 설정되어 있다. 입력이 없으면 약 4.833초에 자연 종료한다. 기존 종료 시각의 저장값은 입력 취소 시각으로 이어받으며, 이미 시전 중인 Q는 시작 시점의 설정을 유지한다.

## 시퀀스와 루트 모션

기본 구성은 `Jump_Combat_Start_0 → Combo_Attack_Air_All → Jump_End_F_0`이다. 공격 구간은 약 3.083초이며 기본 타격 세 개가 이 클립에 연결되어 있다. 이전 합성 Ultimate의 타격 시각은 공격이 시작했던 26/60초를 빼서 원본 클립 시각으로 변환했다. 원본 모션 내부의 전진·후퇴는 보존한다.

기본 시퀀스는 약 4.833초다. 지정한 세 원본의 루트 Y 이동은 0이고 도약 높이는 본의 포즈에 들어 있다. 기본 `루트 높이 Y 적용`은 꺼서 기존 지면 처리를 유지한다. 현재 플레이어 Avatar로 추출한 전체 종점은 시작점 기준 전방 약 8.34m이며, 착지 때 원점으로 복귀하지 않는다.

클립 추가, 복제, 삭제, 순서 변경을 Undo로 되돌릴 수 있다. 복제한 구간의 설정은 원본 구간과 독립적이다. 사용 구간과 배속을 바꾸면 전체 재생 길이와 뒤 구간의 시작 시각을 다시 계산한다. 타격·이펙트 시점 자체는 해당 클립에 남는다.

선택 클립 집중 재생은 해당 구간만 반복하지만 앞 구간에서 누적한 이동 위치를 유지한다. 전체 시퀀스 재생은 모든 구간을 순서대로 평가한다. 편집 중인 클립과 현재 재생 중인 클립은 구분해서 표시하며, 다른 구간이 재생돼도 편집 선택을 강제로 바꾸지 않는다.

루트 이동 추출은 실제 플레이어의 Avatar와 스케일로 별도 모델을 평가한다. 원본 클립 전체를 샘플링하므로 사용 구간과 배속을 바꿔도 다시 추출할 필요가 없다. 클립·Avatar·모델 스케일 또는 원본 에셋이 바뀌면 갱신한다. 미리보기와 런타임은 같은 추출 데이터와 연결 계산을 사용한다.

`자세 연결`은 앞 구간의 마지막 자세에서 현재 구간의 초반 자세로 섞는 시간이다. 두 구간의 재생 시간을 겹치는 방식이 아니며 전체 길이는 줄어들지 않는다. 이동량을 두 번 더하지 않고 루트 경로는 계속 유지한다.

높이 적용 시 기존 지면 유지 이동 대신 루트의 Y 이동을 사용한다. 내려올 때 바닥을 통과하지 않도록 제한하며, 시퀀스 종료·중단 후에는 현재 위치에서 실제 지면으로 내려와 일반 이동으로 복귀한다. 원본 클립에 높이 이동이 포즈로 구워져 있다면 루트 Y 자체는 0일 수 있다. 포즈의 높이와 루트 높이를 중복 적용하지 않는다.

물리 충돌에 막힌 이동량은 나중에 보충해서 순간이동하지 않는다. 히트스톱으로 아직 물리에 전달되지 못한 명령은 보존한다. 루트 궤적은 애니메이션이 의도한 경로이며 실제 벽·지형의 영향은 Play Mode에서 확인한다.

## 이전 수동 이동 모드

`이동 경로` 탭에서 **경로 모드**를 사용하면 시작 위치부터 여러 지점을 거치는 지면 이동을 편집할 수 있다. 지점은 시전 방향 기준 로컬 X/Z 미터와 원본 클립의 도착 시각으로 저장한다. 시작은 0초의 (0, 0)으로 고정되며 마지막 지점에 도착한 뒤에는 그 위치를 유지한다. 지면 높이는 기존 PlayerMover가 처리하므로 이 경로 편집은 수평 이동을 다룬다.

번호가 붙은 지점을 Scene에서 선택해 이동하거나, 현재 시점에 새 지점을 추가한다. 시간축의 이동 마커를 드래그하면 그 지점의 도착 시각이 바뀐다. 구간 보간은 일정한 속도 또는 각 구간에서 가감속하는 방식으로 선택한다. 경로의 선과 시각화는 런타임의 `EvaluateOffset` 계산을 공유하며, 플레이어는 시전 때의 바라보는 방향을 유지한다.

고정 시작점·격자·전체 경로·타격 순간의 위치 표시를 함께 보며 움직임을 비교한다. 전체 경로를 화면에 맞추거나 캐릭터를 따라가는 보기를 선택할 수 있다. 기본 예제 경로는 조절을 시작하기 위한 데이터이며 원본 애니메이션에서 추출한 루트 모션은 아니다. 예제 생성과 직접 편집 모두 Undo를 지원한다.

기존 **전방 이동** 모드는 시작·종료·거리·곡선을 그대로 사용한다. 경로는 움직이는 타깃을 자동 추적하지 않는다. 물리 이동은 기존 PlayerMover를 사용하므로 벽·바닥의 영향은 Play Mode에서 확인한다.

시퀀스가 없는 이전 데이터는 전방 이동·수동 경로 모드를 계속 지원한다. 시퀀스 모드에서는 이 수동 경로 대신 원본 루트 궤적을 표시한다.

시간별 프리팹 이펙트 큐는 각 구간에 추가할 수 있다. 게임에서 해당 원본 클립 시각에 지정한 위치·회전으로 생성한다. 큐 이벤트는 향후 카메라와 사운드를 연결할 수 있는 확장 지점이다. 궁극기 전용 카메라 경로 편집은 이번 시안의 범위에 포함하지 않았다. E의 기존 카메라 타임라인은 E 스킬에서 계속 사용한다.

프리뷰는 자세와 공간·시간 관계를 확인하기 위한 모델이다. 실제 적 이동·벽 차단·피격 반응·카메라 연출을 재현하지 않는다. 범위는 물리 겹침 검사이며 별도의 벽 가림 판정은 없다.

## 타격 흡인

`타격 · 범위`에서 타격을 선택하고 `흡인`을 펼친다. 새 설정을 만들면 선택한 타격에 연결된다. `적용 타격 선택`에서 다른 클립의 타격까지 체크할 수 있다. `설정 복제 후 분리`는 선택한 타격에만 별도 설정을 연결한다.

- `Scene에서 모을 위치 보기`를 누르고 민트색 핸들을 드래그한다. 숫자로 조절하려면 좌우·전방 오프셋을 사용한다. 시간축의 민트색 선은 타격마다 예상되는 지속 구간이다.
- 첫 타격 시 고정은 첫 지정 마커가 빗나가도 그 위치를 공유한다. 각 타격 시 갱신이나 플레이어 추적도 선택할 수 있다.
- 속도, 지속시간, 도착 반경을 기본 조절값으로 사용한다. 고급 설정에서 가속·감속, 목표 도착시간, 저항 판정 강도, 우선순위, 해제 마커를 지정한다. 지속시간은 전투 시간 기준이며 대상의 히트스톱 동안 멈춘다.
- Scene 궤적은 선택 마커가 한 번 적중한 경우의 예상이다. 저장 후 Play Mode의 `연결 · 실행 → 궁극기 시전` 또는 Q로 실제 판정을 확인한다. 시전 중에 바꾼 값은 다음 시전부터 반영된다.
- 현재 예제는 `공중 콤보`의 `01 · 베기`와 `Hit 4`에 `전방 모으기`를 공유한다. 전방 2m, 8m/s, 0.4초, 도착 반경 0.35m다.

Play Mode에서 `Tools → Character → Player → Validate Ultimate Pull (Play Mode)`를 실행하면 실제 적의 흡인, 히트스톱, 벽 충돌과 해제를 검사한다.
