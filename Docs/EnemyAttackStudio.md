# 적 공격 비주얼 에디터

Unity 메뉴 **Tools → Character → Enemy → Attack Studio**에서 엽니다. 적의 `EnemyCore` 컴포넌트 메뉴에 있는 **공격 비주얼 에디터 열기**로도 열 수 있습니다.

## 공격 조정

1. 상단에서 씬의 적을 선택합니다. 현재 Striker의 `Close Attack Hit 1`, `Close Attack Hit 2`가 실제 연결된 공격 데이터에서 자동으로 표시됩니다.
2. 공격을 선택하고 **재생**, **일시정지**, **−1F / +1F**, **타격 순간**으로 포즈를 확인합니다. 드래그로 시점을 회전하고 휠로 확대합니다. 0.25배속과 반복 재생도 지원합니다.
3. 오른쪽 **공격 · 판정**에서 피해량, 판정 모양·크기·중심, 회피 감지 추가 크기, 히트스탑을 조정합니다. 아래 평면도의 빨간 점을 드래그하면 위치가, 흰 점을 드래그하면 크기가 바뀝니다. 평면도의 위쪽은 적의 전방 `+Z`, 격자는 1m입니다.
4. 타임라인의 **빨간 마커**를 드래그해 타격 시점을 변경합니다. 초·프레임 입력 또는 **현재 포즈를 타격 시점으로 지정**도 사용할 수 있습니다. 실제 애니메이션의 `OnAttack` 이벤트를 편집하며 다른 효과음·검 궤적·종료 이벤트는 유지합니다.
5. **변경 저장**을 누릅니다. 편집은 즉시 메모리에 반영되며 `Ctrl+Z`로 되돌릴 수 있습니다. 씬 설정을 함께 편집했다면 해당 씬도 저장합니다.

**빨강은 피해 판정**, **노랑은 회피 감지 여유**, 청록색 캡슐은 거리 비교용 표적입니다. 여러 판정을 추가할 수 있지만 실제 런타임은 판정마다 피해를 적용하므로 겹치는 판정은 피해가 중첩될 수 있습니다. 구 판정은 크기의 가장 큰 축을 지름으로 사용합니다.

## 돌진 확인

미리보기 상단의 **돌진 적용**이 기본 모드입니다. **표적 거리 (m)**와 오른쪽 **최대 돌진 거리 (m)**를 바꾸면 예상 경로가 즉시 갱신됩니다. 재생하거나 타임라인을 움직이면 원본 애니메이션의 루트 이동량에 따라 모델이 경로를 따라 돌진합니다.

- **흰색 출발 원:** 공격 시작 위치입니다. 카메라 중심이 돌진 모델을 따라 움직이지 않아 이동량을 비교할 수 있습니다.
- **청록색 경로·도착 원·도착 판정:** 정면의 고정 표적과 첫 판정 중심 오프셋으로 계산한 예상 도착 위치입니다. 가까운 표적에서는 최대 거리보다 짧게 이동합니다. 굵은 청록선은 현재까지 이동한 거리입니다.
- **보라색 끝선:** 설정한 최대 돌진 거리입니다. 표적 거리와 독립적으로 표시됩니다.
- **화면 위 거리 표시:** 현재 이동량, 예상 도착 거리, 최대 거리를 미터 단위로 비교합니다.

**전체 경로 맞춤**으로 출발점부터 최대 범위까지 다시 볼 수 있습니다. **제자리 / 원본 루트 이동**으로 비교할 수도 있습니다. 드래그 상하 입력은 일반 회전 방향으로 동작하며 위아래 제한과 휠 확대를 유지합니다.

돌진 예측은 런타임처럼 각 평면 루트 델타의 크기에 예상 이동 거리를 곱하고 도착점에서 제한합니다. 클립 길이에 맞춰 이동을 강제로 완성하지 않으므로, 원본 루트 이동이 짧거나 없는 구간은 덜 이동하거나 정지합니다. 실제 표적의 콜라이더 접촉, 움직이는 표적 추적, Animator 전환·블렌드와 앞선 콤보의 이동은 예측에 포함하지 않습니다.

**Scene 뷰에서 직접 편집**을 켜면 선택한 공격의 위치·크기 핸들이 적의 원점에 표시됩니다. 이는 워핑 전의 로컬 판정입니다. 미리보기 모델과 Scene 핸들은 원본 적의 포즈를 재생하거나 이동시키지 않습니다.

## 적용 범위

- **공격 데이터 / 애니메이션:** 해당 에셋을 공유하는 모든 적에게 적용됩니다. 현재 Striker 네 인스턴스는 같은 두 공격을 공유합니다.
- **적 · 전투 AI → 기본 설정 / 플레이어 감지:** 선택한 적 인스턴스의 체력, 경직 저항, 감지 거리를 편집합니다. 프리팹 인스턴스라면 오버라이드로 기록됩니다.
- **씬 전체의 공격 리듬 / 거리 · 포위:** 씬의 공용 컨트롤러 값을 편집하므로 여러 적에게 영향을 줍니다.
- Play Mode에서는 편집이 잠기며, 독립 미리보기는 Edit Mode에서 사용합니다.

## 미리보기의 기준

미리보기는 실제 Animator에 등록된 클립과 `OnAttack` 이벤트 연결을 사용합니다. Striker의 기존 Timeline 에셋은 현재 공격 런타임에서 사용하지 않으므로 편집 대상이 아닙니다.

이 창은 **개별 클립의 포즈와 판정 정의**, 그리고 정면 고정 표적 기준의 **돌진 예측**을 보여줍니다. **원본 루트 이동**은 애니메이션에 기록된 이동만 보여줍니다. 실제 AI 추적, 충돌에 따른 모션 워핑 도착점, Animator 상태 전환·블렌드, 히트스탑, 실제 명중 여부는 게임 실행에서 확인해야 합니다. 돌진 모드의 노란 범위는 예상 도착점 기준이며 나머지 모드는 현재 미리보기 원점 기준입니다.

1타의 **공격 예고 시간**은 공격 시작 전 대기 시간입니다. 2타의 같은 데이터 필드는 추적 회전 각도 계산에 사용되며, 2타 앞에 별도 대기를 넣지 않습니다. 최대 돌진 거리는 고정 이동량이 아니라 상한입니다.

현재 1타의 Animator 전환은 약 **0.604초**부터 시작됩니다. 타임라인에서 전환 이후 구간을 별도로 표시하며, 그 뒤로 타격 시점을 옮기면 실제 전투에서 이벤트가 발생하지 않을 수 있다는 경고가 나옵니다. 동적 BlendTree나 조건부 전환은 이 표시로 예측하지 않습니다.

타격 시점 편집은 `Assets` 아래의 독립 `.anim` 에셋에서 지원합니다. FBX 등에 포함된 가져오기 클립은 Import Settings에서 편집해야 합니다. 같은 공격 이벤트가 여러 번 존재하면 이 창은 첫 이벤트를 편집합니다.

## 검증

**Tools → Character → Enemy → Validate Attack Studio**는 현재 씬의 공격 연결, 임시 복제 클립의 이벤트 보존·시간 제한·Undo/Redo, 가져오기 클립 보호, 미리보기 포즈 변화 및 원본 보존, 돌진 거리 제한·표적 거리·역방향 스크럽·루트 이동량, 카메라 상하 입력과 각도 제한을 확인합니다. 임시 검증 에셋은 완료 후 정리됩니다.
