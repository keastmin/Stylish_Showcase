# 회피 조정 / Dodge Studio

Unity 메뉴 **Tools > Character > Player > Dodge Studio** 또는 회피 설정 Inspector의 **회피 조정 열기 · 애니메이션 자동 재생**으로 연다.

창을 열면 실제 플레이어 Avatar를 사용하는 복제 모델이 정상 속도로 자동 반복 재생된다. 기본은 제자리 재생이며 테스트 대상은 숨겨 모델을 가리지 않는다. 씬에 플레이어가 없으면 플레이어 프리팹을 미리보기 소스로 찾는다.

## 먼저 세 가지 보기 중 선택

| 보기 | 용도 |
|---|---|
| **① 동작만 보기** | 슬로우 없이 회피·반격 애니메이션의 자세를 관찰한다. 전방/후방과 동작을 고르고 프레임을 옮긴다. |
| **② 슬로우 · 화면 연출** | 완벽 회피 성공 후 반격하지 않는 상황을 재생한다. 속도와 화면 효과를 함께 본다. |
| **③ 회피 → 반격** | 반격할 때 속도와 화면 효과가 어떻게 이어지는지 본다. ‘반격 입력’ 슬라이더를 빠르게/중간/늦게로 옮겨 비교한다. |

**Ⅱ 일시정지 / ▶ 재생**, **↻ 처음부터**, **−1/+1 프레임**을 사용한다. ‘처음부터’는 선택한 보기를 유지한다. 관찰 속도 0.25배·0.5배·1배·2배는 관찰용이며 게임 설정은 바꾸지 않는다. ‘동작만 보기’의 한 프레임은 해당 클립의 원본 프레임이며, 연출 보기의 한 단계는 실제 시간 1/60초다.

우클릭 드래그로 카메라를 회전하고 휠로 확대한다. **시점 초기화**로 돌아올 수 있다. **제자리**를 끄면 원본 루트 이동도 볼 수 있다.

## 오른쪽 여섯 가지 조정

### 슬로우

- **시작까지 기다림:** 완벽 회피 성공 후 실제 초.
- **전투 속도 (%):** 100%가 정상 속도다. 8%는 평소보다 약 12.5배 느리다.
- **슬로우 최대 길이:** 느려지는 시간을 포함한 최대 시간이다. 종료 자세나 반격이 먼저 오면 일찍 끝날 수 있다.
- **정상 속도로 돌아오기:** 반격하지 않고 끝났을 때의 복귀 시간이다.

값을 바꾸면 연출 미리보기에 반영된다. **이 설정으로 회피 재생**을 눌러 시작부터 확인할 수도 있다. **고급 > 감속에 걸리는 시간**(기존 ‘느려지는 시간’)은 100%에서 목표 전투 속도까지 내려가는 시간이다. 0초면 즉시 감속하며, 슬로우 유지 길이는 **슬로우 최대 길이**에서 따로 조절한다. 고급에서 진입 곡선과 복귀 조건도 조절한다. 완벽 회피가 슬로우 시작보다 먼저 끝나는 설정이면 경고가 표시되며, **완벽 회피 종료 시점 조정**으로 종료 프레임을 편집할 수 있다.

### 화면 효과

**회피 때 / 반격 때**를 선택하고 효과 목록에서 편집할 효과를 고른다. **+ 추가**에서 비네트·흑백 · 채도·노출·색수차·렌즈 왜곡·카메라 줌·화면 흔들림을 추가할 수 있다.

**회피 때 > 완벽 회피 흑백 · 채도 조정**으로 화면 전체의 부분 흑백 효과를 바로 선택한다. 아직 효과가 없으면 **+ 완벽 회피 · 부분 흑백 추가**로 넣는다. 기본은 **완벽 회피 성공 시**, 흑백 강도 **65%**, 나타남 **0.06초**·유지 **0.24초**·사라짐 **0.28초**, 총 **0.58초**다. 비네트와 함께 잠깐 나타나고 원래 화면 색감으로 돌아온다. 기본 시작 조건에서는 일반 회피에 나타나지 않으며 반격해도 원래 시간대로 마무리된다.

**흑백 강도 (%)**는 0%가 원래 색감, 100%가 완전 흑백이다. 중간값으로 색감이 남는 정도를 조절한다. **흑백으로 바뀌고 돌아오는 과정 재생**으로 시간 흐름을 확인하거나, **흑백이 가장 강한 순간에서 멈춰 보기**로 일시정지한 화면에서 강도를 바꿔 비교한다. 값 변경은 같은 미리보기에 반영되며, 아래 시간축에서도 원하는 순간으로 이동할 수 있다. **고급 > 채도 변화**에서는 -100~100의 원래 채도 범위를 사용해 더 선명한 색감도 설정할 수 있다.

**강도 → 언제 시작? → 추가로 기다림 → 나타나는 시간 → 유지하는 시간 → 사라지는 시간** 순서로 조절한다. 화면 효과의 시간은 슬로우 배율과 독립적인 실제 초 기준이다. 회피 효과에는 **반격하면 이 효과는** 설정이 있다. 원래 시간대로 계속 재생하거나, 현재 강도에서 종료하거나, 같은 종류의 반격 효과로 연결할 수 있다.

색상·곡선·이름·삭제는 **고급** 안에 있다. 화면 효과는 별도 임시 Volume과 실제 URP 후처리로 미리본다. 미리보기 Volume은 해당 카메라 렌더 중에만 활성화된다.

### 잔상 VFX

**잔상 VFX** 탭에서 **기존 잔상 / 컬러 디더 VFX / 기존 + 컬러 디더 VFX / 잔상 끄기**를 선택한다. 기존 설정은 기본적으로 기존 잔상을 유지한다. **제작한 VFX 연결 · 적용**은 `ChromaticAfterimage_VFX.prefab`을 연결하고 새 효과 단독 사용으로 바꾼다. **설정 저장** 후 다음 회피부터 적용되며 E 스킬의 기존 잔상에는 영향을 주지 않는다.

새 VFX는 **회피 시작(일반 회피 포함) / 완벽 회피 성공 / 슬로우 시작** 중 지정한 시점에 한 번 재생한다. 생성 시간, 포즈 간격, 개별 수명, 최대 포즈 수, 불투명도, 노이즈 세밀함, 무기 포함 여부, 푸른 조각·빛점 수, 소멸 경계 색과 밝기를 조절한다. 기존 잔상을 함께 사용하는 경우 기존 효과의 시작 시점은 원래대로 슬로우 시작이다.

시간 기준은 **전투 속도** 또는 **실제 시간**으로 선택하며 두 방식 모두 히트스톱과 전체 일시정지 중에는 멈춘다. **회피 동작 종료 시 생성 중단**은 다른 동작으로 넘어갈 때 새 포즈 생성을 멈추고, 이미 생긴 잔상과 입자는 자연스럽게 소멸시킨다. 플레이어가 비활성화되면 해당 플레이어의 VFX를 정리한다. 잘못된 프리팹이나 연결 누락은 기존 잔상으로 돌아간다.

**이 창에서 입자 VFX 재생**을 누르면 회피 조정 창 안에서 실제 VFX Graph 입자와 포즈 잔상을 함께 재생한다. 편집 모드에서 동작하므로 Play 모드나 별도 씬으로 이동할 필요가 없다. 기존 재생·일시정지·프레임 이동·시간 슬라이더를 그대로 사용한다. 숫자를 바꾸면 미리보기 시뮬레이션을 갱신하며, 시간을 뒤로 옮기면 해당 시점까지의 포즈와 입자를 다시 계산한다. 재계산 중에는 화면에 준비 상태를 표시한다. 생성된 포즈 수와 실제 GPU 입자 수도 모델 위에 표시된다.

**② 슬로우 · 화면 연출**과 **③ 회피 → 반격**에서는 선택한 시작 시점과 전투 속도를 함께 반영한다. **① 동작만 보기**는 기존대로 순수 애니메이션 검사 용도다. 미리보기 버튼은 게임 적용 방식과 설정 저장 상태를 바꾸지 않으며, 기존 잔상 유지·끔 상태에서도 새 VFX만 미리 볼 수 있다. 복제 모델·VFX·카메라는 임시 PreviewScene에 격리하고, 잔상은 미리보기 카메라에만 그린다.

### 판정 · 입력

1. **동작만 보기**에서 원하는 자세를 찾고 일시정지한다.
2. 판정 프레임 슬라이더를 옮기거나 **현재 보이는 자세를 판정 시작으로**를 누른다.
3. 한 프레임 검사와 구간 검사를 고른다. 구간 검사는 처음 성공한 한 번만 확정한다.

프레임을 바꾸면 해당 자세로 바로 이동한다. 원본 시간축의 **노란 마커는 성공 판정**, **보라 마커는 종료 자세**다. 마커도 드래그할 수 있다.

**성공 후 입력 시작 / 입력 가능한 길이**는 반격 버튼을 받을 실제 시간 구간이다. 무적 지연·상한·동작 배속은 고급에 있다. 게임에서는 기존 적의 공격 예고 범위를 실제 성공 조건으로 사용한다.

### 반격 연결

반격 시 **바로 정상 속도로 / 부드럽게 정상 속도로 / 지정한 공격 자세까지 유지** 중 선택한다. 지정 자세를 고르면 해당 반격 애니메이션을 직접 보면서 복귀 프레임을 정할 수 있다.

**반격까지 이어서 재생**으로 확인한다. 반격 입력 시점은 실제로 열리는 입력 구간 안에서 자동 선택하므로, 기본 보기에서 잘못된 시점 때문에 반격이 빠지는 일이 없다. 슬로우 해제와 화면 효과 종료는 독립적이다.

### 종료 시점

**종료 시점** 탭에서 **완벽 회피 종료**를 직접 지정한다. 위의 **전방 회피 / 후방 회피**를 선택한 뒤 **종료 프레임**을 입력하거나, 원하는 자세에서 멈추고 **현재 보이는 자세를 종료 시점으로**를 누른다. 원본 애니메이션 시간축의 보라색 **완벽 회피 종료** 마커도 드래그할 수 있다. 값을 바꾸면 해당 자세로 이동하며 **종료 시점까지 슬로우 확인**으로 연출을 재생할 수 있다.

종료 프레임은 전방·후방별로 저장하고, **지정한 자세에서 종료** 사용 여부는 두 방향에 공통으로 적용한다. 종료 마커는 원본 애니메이션 시간 기준이며 슬로우와 동작 배속에 따라 실제 도달 시각은 달라진다. 반격 입력 시간 만료나 행동 중단이 먼저 오면 그때 종료된다. 슬로우 시작 전 종료되거나 성공 판정 이전에 종료되는 설정에는 경고가 표시된다. **설정 저장** 후 게임의 다음 회피부터 적용된다.

## 시간축과 저장

한 번에 하나의 시간 기준만 표시한다. **동작만 보기**는 원본 프레임이고 **연출 보기**는 실제 초다. 연출 시간축은 동작·슬로우·반격 가능·선택 화면 효과 네 줄이다. 실제 종료 시점에 맞춰 길이를 계산해 불필요하게 긴 정지 구간을 없앴다. 마지막 화면 효과만 남았다면 모델 위에 ‘연출 마무리’가 표시된다. 최대 관찰 길이는 30초이며 게임에서 설정한 지속 시간에는 제한하지 않는다.

**설정 저장**으로 에셋을 저장한다. **기준값 복원**은 창을 열었을 때 또는 마지막 저장 시점으로 돌아간다. 숫자·마커·효과 추가/삭제·기준값 복원은 Ctrl+Z를 지원한다. 진행 중인 회피는 시작 당시 복사본을 사용하므로 변경값은 게임의 다음 회피부터 적용된다.

기존 튜닝 값과 씬·프리팹은 UI 개선 과정에서 바꾸지 않는다. 이미 편집 중이던 미저장 설정도 유지한다.

## 모델 연결과 실제 게임 확인

**모델 · 연결**에서 모델·설정 에셋을 확인하고 모델을 다시 찾을 수 있다. 테스트 대상 표시와 거리·예고 조건 검사는 이 안으로 옮겼다. 기본 연출 미리보기는 성공을 가정한다.

Play Mode 중에도 복제 모델 미리보기를 사용할 수 있다. **실전 기록**은 실제 플레이어의 가장 최근 회피에 대한 이벤트·요청 배율·적용 배율·위치 등을 보며 CSV로 저장하는 화면이다.

미리보기 이동은 플레이어 Avatar로 추출한 원본 궤적이다. 실제 적 AI·벽 차단·반격 접근 보정·타격/VFX 전체는 Game 뷰에서 확인한다. 원본 애니메이션과 기존 반격 타임라인은 수정하지 않는다.

## 검증

- **Tools > Combat > Validate Dodge VFX World Coordinates:** 완벽 회피 성공으로 실제 GPU 입자를 생성하고, 원점·위치 이동·회전·비균일 크기 변경의 네 경우에서 플레이어 주변에 표시되는지 PNG를 비교한다. 임시 복제 설정을 사용하며 원래 설정과 저장 상태를 유지한다. 결과는 `Temp/DodgeVfxCoordinates_After.result`에 남는다. `SourcePose` 메시와 `BoundsCenter`는 월드 좌표이므로 그래프의 Position Mesh Transform과 Initialize Bounds도 World로 유지한다. Local이면 플레이어 변환이 중복되어 입자가 다른 위치에 생성된다.

- **Tools > Combat > Validate Dodge Studio GPU Preview:** Play 모드로 전환하지 않고 툴 내부의 실제 GPU 입자 생성, 일시정지한 이미지의 유지, 역방향 시간 이동, 입자량 변경과 미저장 설정 보존을 검사한다. 잔상 불투명도를 0으로 두고 GPU 입자 렌더러만 껐을 때 화면 픽셀이 변하는지도 비교해 실제 표시 여부를 검증한다. 결과는 `Temp/DodgeVfxPreviewVerification.result`에 남는다.

- **Tools > Combat > Validate Dodge Afterimage Integration:** 저장된 씬 하나가 열린 편집 모드에서 실행한다. 임시 설정으로 실제 플레이어 런타임의 세 시작 시점, 기존/새 VFX/동시/끔, 잘못된 프리팹의 복귀, 포즈 및 GPU 표면 연결, 설정 복사본, 히트스톱·슬로우·일시정지, 동작 종료 시 자연 소멸을 검사한다. 원래 씬으로 돌아오며 설정 에셋을 저장하지 않는다. 결과는 `Temp/DodgeAfterimageVerification.result`에 남는다. 추가된 런타임 검사 22개와 기존 타이밍 검사 36개가 통과했다.

- **Tools > Combat > Validate Dodge Studio Preview:** 창이 보이는 상태에서 실행한다. 전방/후방 회피와 반격 3단계의 본 회전·프레임 샘플링·연속 재생과 실제 렌더링된 몸체 변형을 함께 검사한다. 낫 등 고정 메시를 숨기고 제자리에 고정해 서로 다른 자세의 PNG를 비교하며, 같은 자세로 돌아왔을 때 같은 이미지인지도 검사한다. 검사가 끝나면 무기와 표시 옵션을 복원하고 전방 회피 자동 재생으로 돌아간다. 결과는 Temp/DodgeStudioPreview.result.
- **Validate Dodge Studio Timing / Runtime:** 시간 계산 46개와 런타임을 포함한 84개 검사가 통과했다. 지연 뒤의 감속이 100%에서 시작하는지, 진입 시간을 바꾸면 같은 시각의 속도와 자세가 달라지는지, 30/60/120Hz에서 일치하는지도 검사한다. 실제 플레이어의 전투 속도와 Animator가 지연·진입 시간을 따르는 것까지 확인한다.

이전 28개 검사는 본 회전만 확인했기 때문에, 본은 움직여도 화면의 몸체가 정지하는 문제를 놓쳤다. 실제로 낫과 루트 이동을 제외한 몸체 PNG가 서로 다른 프레임에서도 완전히 같은 것을 재현했다. 원인은 수동 Playable 평가 뒤 PreviewScene의 Game 카메라가 이전 스키닝 행렬을 재사용하는 것이었다. 미리보기 복제 모델의 SkinnedMeshRenderer에만 updateWhenOffscreen과 forceMatrixRecalculationPerRender를 활성화해 렌더마다 변형을 갱신한다.

수정 후 Edit Mode에서 46개 검사가 통과했다. 다섯 동작 각각 몸체만의 이미지에서 10,487~13,636개 픽셀이 변했고, 같은 자세의 재촬영에서는 모두 0개였다. 씬 캐릭터의 Animator 속도가 0이어도 복제 모델은 독립적으로 재생되며, 씬 캐릭터의 스키닝 옵션과 편집 중이던 설정이 유지되는 것도 검사했다. 설정 에셋을 저장하거나 원본 모델·애니메이션을 수정하지 않았다.
