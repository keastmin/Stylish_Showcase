# E Skill Studio

현재 입력은 **E = Skill**, **Q = Ultimate**다. `Tools > Character > Player > E - Skill Studio`에서 E 스킬을 편집한다. Q 궁극기 창은 `Q - Ultimate Studio`다.

## 현재 데이터 모드

E의 이동·타격·화면 효과·입력 시점은 `Assets/07_Datas/Player/PlayerSkill.asset`에 저장한다. `Skill Director > Player Skill Sequence Settings > Definition`이 이 데이터를 연결한다. 시전 시작에 복사하므로 편집은 다음 시전부터 반영된다.

`Tools > Character > Player > Connect E Skill Data`는 기존 9회 타격의 시간·피해·히트스톱·Box/Sphere/Capsule 범위·대상 레이어·Trigger·게이지·진동과 Impact Frame 구간을 가져온다. 애니메이션만 연결한 임시 모델에서 기존 루트 이동을 추출해 거리와 곡선으로 변환한다. 이미 연결된 데이터는 다시 실행해도 덮어쓰지 않는다. 원본 Timeline의 타격 마커와 Collider는 호환용으로 보존한다.

E Studio의 기본 화면은 다음 데이터를 직접 편집한다.

- **타격 · 범위**: 타격별 초/프레임, 추가·복제·삭제·행 순서, 피해·경직·히트스톱·진동, Box/Sphere/Capsule 위치·회전·크기, 레이어·Trigger·명중당 게이지. Scene 핸들은 데이터에 저장된다.
- **이동 · 입력**: 전체 재생 길이와 배속, 이동 시작·끝·거리·곡선, 무적, 입력 취소 허용 시각, 콘텐츠 종료 후 추가 후딜, 다음 동작 블렌드 시간.
- **화면 효과**: 기존 Impact Frame의 시작·길이·사용 여부와 추가 Volume Profile의 시작·길이·최대 가중치·시간 곡선·우선순위.
- **연출 고급**: 기존 애니메이션·VFX·투명도·카메라와 신호를 편집한다. Timeline은 이 연출에 사용하며 게임 이동·타격·종료를 결정하지 않는다.

시간은 배속 적용 전 전체 E 시퀀스의 초다. 입력 취소 허용을 켜면 그 시점부터 이동·공격·사용 가능한 회피 입력으로 E를 조기 종료한다. 입력이 없거나 회피 자원이 부족하면 재생을 계속한다. Q는 기존 전역 즉시 발동 규칙을 따른다. 추가 후딜은 콘텐츠 종료 뒤의 전투 시간이며 배속의 영향을 받지 않는다. 히트스톱 중 재생·이동·후딜·화면 효과는 정지한다.

전체 길이를 줄여도 뒤쪽 타격·이동·화면 효과를 종료 시점으로 당기지 않는다. 종료 이후 마커는 실행하지 않는다. 이동 곡선의 시작과 끝 값은 0과 1로 정규화하므로 거리 값은 해당 이동 구간의 총 전방 거리다. 벽·지형의 실제 이동 차이는 Play Mode에서 확인한다.

콘텐츠 종료 후 마지막 이동 처리나 추가 후딜이 남아 있으면 E의 마지막 포즈를 유지한다. 실제 상태 전환 시 이 포즈에서 다음 동작으로 기본 0.12 전투 초 동안 블렌딩하며, 다음 행동과 입력 처리를 늦추지 않는다. 마지막 Timeline 애니메이션의 Ease Out은 0으로 두어 컨트롤러가 없는 동안 기본 포즈로 섞이지 않게 한다.

데이터 모드에서는 Timeline 타격 알림을 막아 중복 피해를 방지한다. 화면 효과는 전용 런타임 소유권으로 적용하며 종료·중단·Q 전환·플레이어 비활성화 시 임시 Volume, Impact Frame, 카메라·Timeline 바인딩을 정리한다. 데이터의 Definition을 비우면 아래의 기존 Timeline 모드를 사용할 수 있다.

## 기존 Timeline 모드 및 이전 검증 기록

아래 내용은 Definition이 비어 있는 호환 모드와 이전 작업의 기록이다. 데이터 모드에서 게임 로직을 조절할 때는 위 항목을 사용한다.

## Q와 같은 편집 화면

E와 Q는 같은 색상·헤더·클립 선택 띠·재생 도구·타격 마커 행·상세 탭·저장 영역을 사용한다. E의 상단 클립 띠는 실제 Timeline의 애니메이션 클립을 표시하며, 편집할 클립과 현재 재생 위치를 구분한다.

1. 상단에서 플레이어의 `E Skill Director`를 찾고 편집할 애니메이션 클립을 선택한다.
2. `Scene 미리보기`를 열고 `선택 클립 집중 재생` 또는 `전체 시퀀스 재생`을 선택한다. 시작으로 이동·한 프레임 이동·반복·관찰 배속으로 동작을 살펴본다. 관찰 배속은 실제 스킬 배속을 변경하지 않는다.
3. 타격 시간축의 마름모를 선택하거나 드래그해 시점을 조절한다. 행의 위·아래 이동은 목록 순서만 바꾸며 타격 시각과 Hit 필드 연결은 유지한다. 드래그 한 번은 Undo 한 번으로 되돌린다.
4. `타격 · 범위`, `클립 · 시퀀스`, `연출`, `연결 · 실행`에서 상세 값을 조절한다. `연출` 안에서 이펙트와 카메라를 선택한다.
5. 범위를 편집할 때는 타격을 선택하고 `마커로 이동`한다. Scene 히트박스와 핸들은 사용 중인 타격의 해당 프레임에만 표시된다. 저장 후 게임에서 E로 확인한다.

E의 타격·시그널·이펙트·카메라 시각은 **전체 Timeline의 초**다. 원본 시간 표시와 스크럽은 애니메이션의 시작·트림·배속을 계산해 같은 자세를 찾는다. Q처럼 타격 시각을 각 원본 클립 내부에 저장하는 방식은 아니다. 애니메이션의 시작·트림·배속을 바꾸면 타격과 연출의 전체 시각도 확인하고 필요한 항목을 함께 조절한다. 상세한 트랙 편집은 `Timeline 열기`를 사용한다.

## 조절 항목

- **타격 · 범위**: 마커 사용 여부·시각·행 순서, Hit 필드 선택, 피해량, 공격 단계, 히트스톱, 대상 레이어. 실제 Box/Sphere/Capsule 콜라이더의 위치·회전·범위를 숫자와 Scene 핸들로 편집한다. 사용을 끈 마커는 게임에서 피해와 타격 진동을 발생시키지 않는다.
- **클립 · 시퀀스**: 애니메이션·연출 클립의 시작, 길이, 원본 시작, 배속과 시그널 시각. 초와 Timeline의 프레임 단위로 확인한다.
- **연출 → 이펙트**: 실제 Control 클립의 재생 구간과 연결 오브젝트, 위치·회전·크기. Opacity와 Impact Frame도 기존 Timeline 설정을 그대로 사용한다.
- **연출 → 카메라**: 기본 위치·각도, 플레이어 이동 추적, 시간별 위치·회전·FOV 키, 활성 구간, TPS 복귀 시그널, 진동과 마지막 충격.
- **연결 · 실행**: 실제 플레이어·Director·Timeline 연결과 종료 시간·후딜 설정을 확인한다.

상단의 미리보기는 Unity Timeline의 Preview와 같은 재생·스크럽 기능을 사용한다. Timeline과 Game/Scene 뷰를 함께 보면 이펙트와 카메라 결과를 확인할 수 있다. 편집 모드에서는 데미지를 발생시키지 않는다.

## 종료 시간

Skill Director의 `Player Skill Sequence Settings`에서 자동 종료를 사용하면 Timeline 길이에 맞춰 E가 끝난다. 기존 2.2초 하드코딩을 제거했으므로 현재 약 **2.683초**의 시퀀스를 끝까지 재생한다. 클립 길이를 늘리면 실제 스킬 종료도 따라간다.

자동 종료를 끄면 직접 종료 시각을 지정할 수 있다. 기존 복귀 시점을 원하면 `2.2`초를 지정한다. 종료 시각은 Timeline의 재생 길이를 넘을 수 없다. 별도의 후딜 시간은 Timeline 정리 후 조작이 돌아오기까지의 시간이다. 히트스톱 중에는 시퀀스와 후딜 시간이 진행되지 않는다.

## 카메라 무빙

`Motion Enabled`를 켜고 키를 추가한다. `time`은 E Timeline 시작부터의 초, `offset`은 시전 방향 기준 위치(X 오른쪽, Y 높이, Z 전방), `euler`는 회전, `fieldOfView`는 화각이다. 보간 방식은 해당 키에서 다음 키로 향하는 구간에 적용된다.

키 순서와 무관하게 시각으로 평가하며 첫 키 이전에는 첫 키, 마지막 키 이후에는 마지막 키를 유지한다. 같은 시각의 키는 목록의 마지막 항목이 우선한다. `Follow Player Movement`를 끄면 시전 위치를 기준으로 카메라를 움직인다. 무빙을 끄거나 키가 없으면 기존 기본 위치와 각도를 사용한다. 초기값은 기존 연출을 유지하도록 무빙을 꺼 두었다.

키는 카메라 활성 구간 안에 배치한다. 위치 설정 시그널은 활성 시작보다 먼저, TPS 리센터는 활성 종료보다 먼저 둔다. 카메라 종료 시각은 TPS 복귀 블렌드의 시작이며 복귀 블렌드 길이는 Main Camera Brain의 Custom Blends를 따른다. 중단·종료·미리보기 해제 때 임시 위치·회전·화각을 복원한다.

## 저장 범위

Timeline의 클립·마커·노이즈 설정은 공용 에셋이다. 같은 Timeline을 사용하는 씬에 함께 적용된다. 데미지 필드, 히트박스, 이펙트 오브젝트 배치, 카메라 연결·무빙은 선택한 씬/프리팹의 설정이다. 다른 씬에 같은 오브젝트 설정을 적용하려면 Unity의 프리팹 오버라이드 작업을 사용한다.

이전 데이터의 타격 필드 번호 `0`은 시간순 자동 연결이다. 새 툴은 마커를 옮기거나 행 순서를 바꾸기 전에 현재 실제 연결 번호를 `1~12`로 고정한다. 마커 이름으로 번호를 추정하지 않으므로, 이름과 실제 Hit 필드가 다르던 기존 타격도 그대로 유지한다. 같은 Hit 번호를 쓰는 마커는 피해·범위를 공유한다. 공격용 콜라이더는 충돌을 켜지 않고 쿼리로 사용한다.

행 순서는 마커의 별도 표시 정보다. 같은 시각의 타격 실행 순서, 데미지 필드, 타격 시점과 독립적이다. 사용 여부를 끄더라도 기존 자동 연결 데이터에서 다른 마커의 필드 번호가 밀리지 않는다.

`Connect E Skill Studio`는 플레이어 프리팹과 현재 열린 씬에 종료 시간 설정을 보완하고, 연결된 Timeline 타격의 현재 Hit 필드와 행 순서를 고정한다. 반복 실행해도 이미 변환된 데이터는 다시 바꾸지 않는다. 기존 타격 시각·피해량·이펙트·카메라 데이터를 초기화하지 않는다.

화면 통합 전 파일은 `C:/Users/kemin/Unity/ProjectR_TaskBackups/20261107_EStudioUnified_Before`에 보존했다. 기존 커밋되지 않은 작업도 포함하므로, 이전 작업을 보존하려면 Git HEAD 초기화 대신 이 백업과 변경 파일을 비교한다.
