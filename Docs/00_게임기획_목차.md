# ProjectR 게임 기획

작성일: 2026-11-07 · 상태: 초기 방향 정리

보스마다 다른 콘셉트의 스테이지를 차례로 돌파하는 3인칭 액션 게임의 기본 기획이다. 각 스테이지는 짧은 일반 적 전투와 보스전으로 구성한다. 제작에 필요한 큰 틀을 정리하며, 세부 수치와 구현 방법은 이후에 정한다.

## 문서를 읽는 기준

- **기본 방향**: 이번 요청에서 정한 메뉴와 게임 진행 구조다.
- **초안 제안**: 기본 방향을 연결하기 위해 제안한 운영 방식이다. 제작하면서 변경할 수 있다.
- **예시**: 콘셉트를 설명하기 위한 가안이다. 실제 콘텐츠나 스테이지 수가 확정된 것은 아니다.
- **미정**: 후속 기획 또는 플레이 확인이 필요한 항목이다.

기존 프로젝트 문서의 3인칭 스타일리시 액션 방향을 바탕으로 작성했다. 이 문서 묶음은 앞으로 만들 게임의 기획이며, 기능의 구현 완료 여부를 나타내지 않는다. 기존 전투 기술 문서와 조작 설명은 별도로 유지한다.
