# 04. 스테이지와 보스

## 스테이지의 기본 단위

각 스테이지는 하나의 대표 보스를 중심으로 구성한다. 보스의 성격이 배경 분위기, 이동 경로, 일반 적 배치, 보스전 공간에 함께 드러나도록 한다.

```text
진입 공간 → 짧은 일반 적 전투 공간 → 보스 진입 지점 → 보스 전투 공간 → 클리어
```

이 구분은 플레이 흐름을 설명한다. 실제 공간을 모두 별도 구역으로 나눌 필요는 없으며, 같은 공간에서 일반 적 전투가 끝난 후 보스가 등장하는 구성도 가능하다.

## 구간별 역할 — 초안 제안

| 구간 | 역할 | 설계 기준 |
| --- | --- | --- |
| 진입 | 스테이지 분위기와 목표를 전달한다. | 진행 방향과 보스의 존재를 쉽게 알아볼 수 있게 한다. |
| 일반 적 전투 | 몸을 풀고 이번 전투 주제를 경험한다. | 적 수와 이동량을 조절해 짧은 전투를 만든다. |
| 보스 진입 | 일반 전투에서 보스전으로 긴장감을 전환한다. | 시선, 소리, 짧은 등장 연출 등을 활용한다. |
| 보스 전투 | 보스의 핵심 패턴과 플레이어 대응을 펼친다. | 이동과 회피 공간, 시야, 카메라 동작을 확보한다. |
| 클리어 | 승리와 다음 진행을 전달한다. | 전투 종료와 이동 가능한 상태를 분명히 보여준다. |

## 보스와 레벨 디자인을 연결하는 방법

먼저 보스전에서 요구할 행동을 정하고, 그 행동이 잘 드러나는 공간을 설계한다. 돌진을 피하는 전투라면 공격 방향을 읽고 옆으로 빠질 여유가 필요하다. 위치를 바꾸는 전투라면 이동할 곳과 위험한 곳이 명확히 구분되어야 한다.

일반 적 구간에서는 같은 주제를 더 단순하게 경험하도록 한다. 보스의 모든 패턴을 미리 보여주기보다, 보스전에 도움이 되는 한 가지 감각을 익히게 한다.
