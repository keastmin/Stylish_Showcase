# 05. 제작 범위와 미정 사항

## 우선 제작할 범위 — 초안 제안

첫 목표는 하나의 스테이지를 처음부터 끝까지 플레이할 수 있게 만드는 것이다. 이후 두 번째 스테이지를 연결해 선형 진행과 시작 지점 선택을 확인한다.

| 단계 | 제작 내용 | 확인할 경험 |
| --- | --- | --- |
| 1. 한 스테이지 완성 | 진입, 짧은 일반 적 전투, 보스전, 클리어, 사망과 재도전 | 준비 전투와 보스전이 한 흐름으로 느껴지는가? |
| 2. 메뉴와 진행 연결 | 네 가지 시작 메뉴, 스테이지 선택, 두 번째 스테이지 연결, 마지막 클리어 처리 | 처음부터 시작하거나 중간 스테이지부터 시작하는 흐름이 자연스러운가? |
| 3. 스테이지 확장 | 다른 콘셉트의 보스와 공간, 적 배치, 전투 난이도 조정 | 스테이지마다 다른 대응과 재미가 생기는가? |
| 4. 경험 다듬기 | 화면 안내, 전환 연출, 설정, 진행 기록 정리 | 진행 상태와 다음 행동을 쉽게 이해할 수 있는가? |

초기 개발 중에는 제작된 스테이지를 모두 선택할 수 있게 두는 편이 확인에 편리하다. 정식 게임의 해금 정책은 별도로 결정한다.

## 첫 플레이에서 확인할 것

- 일반 적 전투가 짧은 준비 구간으로 느껴지고 보스 진입을 지나치게 늦추지 않는가?
- 일반 적을 상대하며 익힌 행동이 해당 보스전에도 도움이 되는가?
- 보스가 무엇을 하려는지, 언제 피하고 공격해야 하는지 읽을 수 있는가?
- 보스 콘셉트와 전투 공간이 서로 잘 맞는가?
- 스테이지 선택 시 해당 스테이지의 일반 적 전투부터 시작되는가?
- 클리어, 사망, 재도전, 메뉴 복귀가 끊김 없이 연결되는가?

## 후속 기획에서 정할 사항

| 항목 | 결정할 내용 |
| --- | --- |
| 콘텐츠 규모 | 전체 스테이지 수, 보스 목록과 순서, 대략적인 플레이 분량 |
| 스테이지 선택 | 처음부터 전체 공개할지, 진행에 따라 해금할지 |
| 선택 후 진행 | 선택한 스테이지 이후에도 선형 진행하는 초안을 최종 채택할지 |
| 재도전 | 보스전 직전과 스테이지 시작 중 어디에서 다시 시작할지 |
| 체력과 자원 | 보스 진입, 재도전, 다음 스테이지 진입 시 어떻게 처리할지 |
| 저장과 기록 | 설정·클리어 기록·중단한 진행 중 무엇을 저장하고 어떻게 복원할지 |
| 새 시작 | 기존 진행과 클리어 기록을 어떻게 처리할지 |
| 플레이어 구성 | 제공할 액션과 스킬, 스테이지 선택 시 시작 상태 |
| 마무리 | 마지막 보스 이후의 클리어 화면과 연출 범위 |

## 기획을 구체화하는 순서

첫 보스의 전투 주제와 공간을 정하고, 그 주제를 준비시키는 일반 적 구간을 붙인다. 한 스테이지를 플레이하면서 길이와 재도전 흐름을 조정한 뒤, 다른 전투 주제를 가진 다음 스테이지를 만든다.

상세 수치와 추가 시스템은 이 과정에서 필요가 확인될 때 별도 문서로 확장한다. 이 문서 묶음은 게임의 기본 구조를 공유하는 기준으로 유지한다.
