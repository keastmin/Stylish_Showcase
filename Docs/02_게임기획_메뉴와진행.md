# 02. 메뉴와 진행

## 시작 메뉴 — 기본 방향

게임을 실행하면 다음 네 가지 메뉴를 표시한다.

| 메뉴 | 역할 |
| --- | --- |
| 새 시작 | 첫 스테이지부터 새로운 플레이를 시작한다. |
| 스테이지 선택 | 시작할 보스 스테이지를 고른다. |
| 설정 | 플레이 환경을 조절한다. |
| 종료 | 게임을 종료한다. |

## 새 시작

첫 스테이지의 진입 구간부터 시작한다. 일반 적 전투를 끝내고 보스를 처치하면 다음 스테이지로 넘어가며, 마지막 스테이지까지 정해진 순서를 따른다.

```text
새 시작 → 스테이지 1 [일반 적 → 보스]
        → 스테이지 2 [일반 적 → 보스]
        → … → 마지막 스테이지 → 전체 클리어
```

기존 클리어 기록을 초기화할지, 별도로 유지할지는 저장 정책과 함께 정한다. 새 시작은 우선 진행의 시작점을 첫 스테이지로 정하는 기능으로 본다.

## 스테이지 선택

보스 또는 스테이지를 식별할 수 있는 목록에서 시작 지점을 선택한다. 선택한 스테이지의 짧은 일반 적 전투부터 진행하고, 이어서 해당 보스를 상대한다.

**초안 제안:** 선택한 스테이지를 클리어하면 다음 번호의 스테이지로 이어진다. 예를 들어 스테이지 3을 선택하면 3 → 4 → … → 마지막 스테이지 순서로 진행한다. 선택은 전체 전투 흐름의 시작 지점을 바꾸는 역할이다.

목록에는 스테이지 이름, 보스 이름, 대표 이미지를 간단히 보여주는 방향을 제안한다. 모든 스테이지를 처음부터 선택할 수 있을지, 진행에 따라 해금할지는 미정이다.

## 설정 — 초안 제안

- 사운드: 전체 음량, 배경음, 효과음.
- 카메라와 조작: 시점 감도, 기본 조작 안내.
- 화면: 해상도와 화면 모드 등 필요한 기본 항목.

실제 제공 항목과 지원 입력 장치는 제작 범위에 맞춰 정한다.

## 플레이 중 흐름 — 초안 제안

| 상황 | 기본 동작 제안 |
| --- | --- |
| 일반 적 전투 완료 | 보스 구역으로 가는 경로 또는 진입 조건이 열린다. |
| 보스 처치 | 짧은 클리어 표시 후 다음 스테이지 진행을 안내한다. |
| 마지막 보스 처치 | 전체 클리어를 표시하고 메인 메뉴로 돌아간다. |
| 플레이어 사망 | 재도전 또는 메인 메뉴 복귀를 선택한다. |
| 일시정지 | 계속하기, 설정, 메인 메뉴 복귀를 제공한다. |

보스전에서 사망했을 때 보스전부터 재도전할지, 스테이지 전체를 다시 시작할지는 미정이다. 클리어 후 자동 이동 여부, 중단한 진행의 저장과 복원 방식도 후속 기획에서 정한다.
