# 01. 게임 개요

## 한 문장 소개

보스의 개성이 반영된 스테이지에서 짧은 일반 적 전투를 거친 뒤 보스와 맞서고, 다음 스테이지로 이어지는 3인칭 스타일리시 액션 게임.

## 기본 방향

| 항목 | 내용 |
| --- | --- |
| 장르와 시점 | 기존 프로젝트 방향인 3D, 3인칭 스타일리시 액션 |
| 시작 메뉴 | 새 시작 / 스테이지 선택 / 설정 / 종료 |
| 새 시작 | 첫 스테이지부터 정해진 순서로 진행 |
| 스테이지 선택 | 어느 보스 스테이지부터 시작할지 선택 |
| 스테이지 구성 | 보스 콘셉트에 맞는 공간 → 짧은 일반 적 전투 → 해당 보스전 |
| 전체 구조 | 스테이지를 클리어하며 같은 기본 전투 흐름을 반복 |

여기서 반복은 하나의 공간을 계속 도는 의미가 아니라, 보스와 공간이 바뀌면서 일반 적 전투와 보스전의 구성이 이어지는 의미다. 각 스테이지의 중심은 해당 보스와의 대결이다.

## 플레이어가 느껴야 할 재미

- **짧고 선명한 전투 흐름**: 일반 적을 상대하며 몸을 풀고, 긴장감 있는 보스전으로 자연스럽게 넘어간다.
- **행동을 읽고 대응하는 재미**: 공격할 때와 피할 때를 판단하고, 보스의 빈틈을 이용한다.
- **액션의 손맛**: 공격 연계, 회피와 반격, 스킬 사용이 타격과 연출로 분명하게 전달된다.
- **스테이지마다 달라지는 경험**: 배경과 보스 외형뿐 아니라 거리 유지, 이동, 공격 타이밍도 달라진다.

## 기본 플레이 흐름

```text
메인 메뉴
  → 첫 스테이지 또는 선택한 스테이지 시작
  → 짧은 진입 구간
  → 일반 적 전투
  → 보스 등장
  → 보스전
  → 스테이지 클리어
  → 다음 스테이지에서 같은 구조로 진행
  → 마지막 보스 클리어 후 마무리
```

새 시작의 선형 진행은 기본 방향이다. 스테이지 선택 이후에도 다음 스테이지로 이어지는 방식은 [메뉴와 진행 문서](02_게임기획_메뉴와진행.md)의 초안 제안을 따른다.

## 기획의 우선순위

먼저 한 스테이지 안에서 일반 적 전투와 보스전이 자연스럽게 연결되고, 보스와 다시 싸우고 싶을 만큼 전투가 재미있는지를 확인한다. 이후 보스와 공간의 차이를 늘려 전체 진행에 변화를 준다.

서사, 성장, 장비 등 추가 요소의 도입 여부는 핵심 전투 흐름을 확인한 뒤 정한다.
